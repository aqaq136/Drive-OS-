# Egor Drive OS · Topway TS10

Проект собственной Android-прошивки для Topway TS10 (UIS7862, Android 10).
Готовой установочной ROM пока нет; проверка OEM обновления/загрузки и аппаратные
испытания ещё не завершены.

## Диагностика TS10 без ADB

[Релиз TS10 Diagnostics 0.1](https://github.com/aqaq136/Drive-OS-/releases/tag/diagnostics-v0.1.0)
содержит небольшой APK для ручного сбора доступных сведений о системе,
загрузке и экране с экспортом JSON на USB. Для скачивания с телефона есть ZIP.

Это обычное приложение Android 10, не прошивка и не MCU update.
В текущем релизе опубликован только диагностический APK с сопроводительными
файлами. На реальной TS10 он ещё не проверялся; подробности и SHA-256 — в релизе.
